# Nesma Madad — Brand Creative System (v3, Art-Director Spec)

## Brand Attributes

Premium B2B commercial furniture house. Voice: confident, understated, architectural. Furniture reads **heavy, durable, meticulously crafted**. Editorial, museum-quality restraint.

## Palette (HARD — strictly enforce)

- **Deep Navy Blue** `#1C2B4A` — primary brand color (headers, ribbon, icons, accents)
- **Matte Black** `#141416` — type, deep grounding
- **Walnut Wood** `#5C4433` — warm material accent
- **Soft Architectural Grey** `#C9CCD1` — secondary fields/rules
- **Soft Studio Grey** `#F4F4F4` — product-cutout background ONLY
- **FORBIDDEN:** cyan, teal, turquoise, mint, neon, any bright saturated accent. (Retires the old turquoise theme entirely.)

## Typography

- Clean, minimalist **sans-serif**. Max 3 levels (Title → Subhead → Body/Caption).
- Perfect spelling + alignment. NO overlapping text, pseudo-text, spelling artifacts, clipping, or captions running off-edge. (e.g. "OFFICE", never "DEFICE".)
- Generous, uniform margins; consistent hierarchy on every page.

## Iconography

- Custom, **heavy-weight, minimalist vector** icons, in Navy `#1C2B4A` or Charcoal `#141416` only. No thin/line-art, no color.

## Section headers (standardize — every sector page)

Format: `SECTOR 0X | NAME`, navy, uppercase, uniform placement/size:

- `SECTOR 01 | CORPORATE SUITES`
- `SECTOR 02 | CASUAL DINING`
- `SECTOR 03 | FINE DINING`
- `SECTOR 04 | HOSPITALITY & LOUNGES`

## Asset generation rules

- **Lifestyle renders:** wide, cinematic architectural spaces (corporate suites, fine dining, lobbies), warm natural sunlight, full-bleed. Furniture heavy, durable, crafted.
- **Product cutouts:** individual chairs/desks/tables on **Soft Studio Grey `#F4F4F4`**, IDENTICAL lighting angle across all product shots for catalog consistency.
- **Material swatches:** NO website-style UI boxes. Render Leather / Wood / Terrazzo / Metal as **seamless, edge-to-edge macro-photography textures**, navy/charcoal labels set directly.

## Layout structure

- Uniform spacing, margins, hierarchy on every page.
- Footer: navy/charcoal Nesma Madad wordmark (left) + nesma-madad.com (right). No teal ribbon, no blue side arc.
- No background text clipping, no overlapping captions.

## Compliance rubric (yes/no)

1. Palette only navy/black/walnut/grey — zero cyan/teal/neon?
2. Sans-serif, perfect spelling, no overlap/clipping?
3. Icons heavy navy/charcoal vectors?
4. Product cutouts on #F4F4F4 with consistent lighting?
5. Materials edge-to-edge macro (no UI boxes)?
6. Header exactly `SECTOR 0X | NAME`?
7. Uniform margins/hierarchy + navy footer?
